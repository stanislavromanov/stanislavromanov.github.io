I developed a proof-of-concept application for creating interactive branching storylines. This tool, designed for a storytelling-focused company, was built using Firebase for real-time data synchronization, React for a dynamic and responsive user interface, and OpenAI for generating AI-content. The application allows users to create, visualize, and manage story branches with ease, offering features like drag-and-drop arrangement, story summaries, and AI-driven content suggestions.
