Works > GastroHero

Designed and built a full-stack monitoring tool for GastroHero, a commercial kitchen equipment retailer operating across 4 European markets (DE, AT, CH, FR). The platform crawls each storefront daily using market-specific adapters for Magento, Shopify, Vue Storefront, Epoq, and Algolia, then compares pricing, availability, promotions, and delivery promises against the German reference market. Features a React dashboard with run history, filterable findings by severity and type, SKU management, and PDF/CSV report generation using Typst. The backend handles parallel browser-based crawling with configurable concurrency, automatic retries, and a cron scheduler. Sole developer on the project, from architecture and adapter reverse-engineering to deployment via Docker Compose with NGINX reverse proxy.
